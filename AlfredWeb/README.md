# AI Financial Assistant — Frontend MVP

Frontend Angular simples para o MVP de um assessor financeiro com IA.

## Requisitos
- Node.js 22.19.0 (o projeto inclui `.nvmrc`)
- npm

## Executar
```bash
nvm use
npm install
npm start
```
Abra http://localhost:4200.

## O que já existe
- Interface responsiva de chat
- Histórico local/mock
- Entrada por texto
- Botão de áudio com estado de gravação mockado

## Próximos passos

- API backend
